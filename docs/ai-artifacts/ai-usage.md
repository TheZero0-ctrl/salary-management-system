# Backend Development

## Setup

- First I created the spec file for the salary management system with the help of AI on [spec.md](../spec.md)
- Then I used the command `/feature-plan` to generate the plan for doing tdd on [api-feature-implementation-plan.md](../api-feature-implementation-plan.md)
  which I review and keep improving it with the help of command `/feature-spec-review` 

## Implementation
- after reviewing and making improvements on [api-feature-implementation-plan.md](../api-feature-implementation-plan.md)
  I started running agents for doing the tdd one step at a time with the command `/feature-tdd-implementation`
  After each RED GREEN cycle I review the code and either make manual change or prompt ai to make change then complete the cycle with REFACTOR
